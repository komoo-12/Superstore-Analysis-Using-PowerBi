# Superstore-Analysis-Using-PowerBi
An interactive business intelligence project analysing retail sales, profitability, customer segments, regional performance  using Microsoft Power BI.
### Project Overview
This project uses the Superstore dataset to analyse historical retail transactions and generate insights that can support business decision-making.

The dashboard explores overall business performance, identifies profitable and loss-making product categories, examines customer purchasing patterns.
### Tools and Technologies
  Microsoft Power BI: Dashboard development and data visualisation.
  Power Query: Data cleaning and transformation.
  DAX: Measures, calculated columns and KPI calculations.
  CSV: Dataset storage and data source.
  ### Business Questions
  This project seeks to answer the following questions:
  1. What are the overall sales, profit and profit margin?
  2. How do sales change across different years and months?
  3. Which product categories and sub-categories generate the highest profit?
 4. Which regions contribute the most to sales and profitability?
 5. Which customer segment generates the highest revenue?
### Dataset Description
The dataset contains retail transaction records from 2014 to 2017.
Key fields include:
* Order ID and Order Date
* Ship Date and Ship Mode
* Customer ID and Customer Name
* Segment
* Region, State and City
* Category and Sub-Category
* Product Name
* Sales, Quantity and Profit
### Data Cleaning and preparation
 * Reviewing and correcting column data types.
  * Converting order and shipping dates to date format.
  *  Maintaining appropriate data types for identifiers.
  *  Checking for missing values and inconsistencies.
  * Creating a Shipping Days column.
 * Preparing date fields for time-based analysis.

### Key Insights
The analysis revealed that:
Total sales amounted to approximately $2.30 million.
Total profit was approximately $286.40 thousand.
Overall profit margin was 12.47%.
Technology generated the highest profit among the three product categories.
Office Supplies also contributed significantly to overall profit.
Furniture generated considerably lower profit compared with Technology and Office Supplies.
The Consumer segment contributed the largest share of sales.
